# El Despertar - recursos y instalador

- `ElDespertar-Recursos.zip`: paquete de texturas del servidor (lo envia el servidor solo al entrar).
- `INSTALAR_CLIENTE.bat` + `INSTALAR_CLIENTE.ps1`: instalan Fabric 1.21.11, la voz de proximidad y el minimapa (descargan los mods desde Modrinth y comprueban su huella). Descarga ambos archivos en la misma carpeta y ejecuta el .bat.
